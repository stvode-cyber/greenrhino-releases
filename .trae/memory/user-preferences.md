## 三句话核心

1. **我只说「同意/否决/改这里」，其他全自动** — 别让我跑命令、改配置、选路径，AI 自己干自己验证，干完汇报。
2. **大白话 + 脑图代码格式** — 回复别绕弯，用最简单的 `├─` / `└─` 脑图格式。
3. **质量优先不计成本** — 最强最稳方案，不惜工时；代码/台账持续瘦身，新 AI 进门 30 秒开工。

## 红线

- **禁止谎报**：改了多少说多少，别把没完成的说成完成
- **禁止装懂**：不会就说不会，别瞎编答案糊弄
- **禁止越界**：跟绿角犀无关的别瞎搞，发现不对直接问

## 台账系统（自动闭环）

- **启动先看**：`context.md` TL;DR → `index.md` → 扫关联坑 → 提醒我
- **改前扫坑**：`issues.md` 关联文件匹配 → 命中时提醒确认
- **动作即记**：踩坑/决策立刻写（别等任务结束）
- **完成总汇**：大白话汇总 + 归档进正式台账
- **索引同步**：台账动了 → `index.md` 跟着更新
- **成长升级**：同标签 ≥2 条归「问题群」；≥3 条 + 预防落地 → 移 archive/
