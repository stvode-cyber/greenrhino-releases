## 🚨 你现在的第一优先级：解 ISS-001（RhinoBridge.getLyric 调不通）

### 立即可执行的诊断命令

```powershell
# 1. 验证 RhinoBridge 在 window 上到底有什么
adb logcat -c
adb shell am force-stop com.greenrhino.music
Start-Sleep -Milliseconds 500
adb shell am start -n com.greenrhino.music/.MainActivity
Start-Sleep -Seconds 6

# 2. 看 RhinoBridge 注册日志
adb logcat -d -s GreenRhino:D GreenRhino:E 2>&1 | Select-String "RhinoBridge"

# 3. 看 JS 层 /api/lyric 错误（如果还有说明 RhinoBridge 没生效）
adb logcat -d -s GreenRhino/JS:F 2>&1 | Select-String "/api/lyric"

# 4. 看 RhinoBridge.setPlaying（验证 RhinoBridge 确实在用）
adb logcat -d -s GreenRhino:D 2>&1 | Select-String "setPlaying"
```

### 同步检测 RhinoBridge 方法列表（必做！）

在 Kotlin `onPageFinished` 里**只加这一个 evaluateJavascript**（1 个，不要多！多了会秒退）：

```kotlin
// 在已有的 onPageFinished evaluateJavascript 之前加
webView.evaluateJavascript(
    "(function(){var r=window.RhinoBridge;var k=[];if(r){for(var m in r){k.push(m);}}return JSON.stringify({exists:!!r,keys:k,getLyricType:typeof(r&&r.getLyric)});})()"
) { result -> Log.d("GreenRhino", "🔧 RB SYNC: $result") }
```

然后 build → install → run → 看 logcat：
- 如果 `{"exists":true,"keys":["toggleFullscreen","setPlaying","requestAutoImport","lookupMediaUri"],"getLyricType":"undefined"}` → **getLyric 没被暴露！** 虽然有 @JavascriptInterface
- 如果 `{"exists":true,"keys":[...,"getLyric"],"getLyricType":"function"}` → 那就是前端代码没走到 fetchOnlineLyric

### 如果 keys 里没有 getLyric

Kotlin inner class 可能有问题。对比 lookupMediaUri（已在用）和 getLyric 的定义：
- lookupMediaUri 返回 String，**同步**做 contentResolver 查询
- getLyric 返回 String，**异步**做网络请求（CompletableFuture + Thread）
- 会不会是 **@JavascriptInterface 方法里不能起后台线程 + CompletableFuture**？

试这个简化版（把网络请求放在主线程，先验证能不能暴露）：

```kotlin
@android.webkit.JavascriptInterface
fun getLyric(title: String, artist: String): String {
    Log.d("GreenRhino", "🎤 getLyric CALLED! title=$title")
    if (title.isBlank()) return ""
    // 简化：先只调 LRCLIB 同步（在 Android WebView @JavascriptInterface 里网络请求是允许的，超时 6s）
    val result = fetchLrclib(title, artist)
    Log.d("GreenRhino", "🎤 getLyric returning ${result.length} chars")
    return result
}
```

### 如果 keys 里有 getLyric 但前端 typeof 检测不到

前端代码可能被覆盖了。检查 assets/pwa/src/lyricFetch.js 里是不是有 RhinoBridge 检测：

```powershell
Select-String -Path "clients\android-music\app\src\main\assets\pwa\src\lyricFetch.js" -Pattern "RhinoBridge"
```
