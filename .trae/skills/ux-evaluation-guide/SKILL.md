# UX 评估指南（绿角犀专属）

> 三个 UX Agent 共用的评估方法、打分体系、改进建议库。
> 适用于：ux-flow-tester（流程走查）、ux-clarity-auditor（易懂性审计）、ux-onboarding-designer（首次体验）。

---

## 一、评估前必做：建立用户画像

绿角犀的典型用户（按优先级）：

| 画像 | 特征 | 核心诉求 | 关注什么 |
|---|---|---|---|
| 🎧 通勤用户 | 上下班路上听音乐，用 Android | 快速打开 → 选歌 → 播 | 启动速度、离线、后台播放 |
| 🏠 家庭用户 | Windows 桌面放着听/看，大屏 | 本地文件管理、后台挂 | 大按钮、收藏、搜索 |
| 📱 学生党 | 宿舍用 Huawei 手机，看视频 | 本地视频 + 字幕 | 字幕加载、全屏、快进 |
| 🖥️ HTPC 用户 | 客厅大屏投屏 | Chromecast/DLNA | 投屏体验、遥控器操作 |

**审计时选择至少 1 个画像，按其视角评估**。

## 二、严重度统一打分（三个 Agent 共用）

| 级别 | 定义 | 对应用户流失概率 |
|---|---|---|
| 🔴 **P0 阻断** | 用户完全无法继续使用该功能 | 90% 流失 |
| 🟠 **P1 核心** | 用户能继续但感到困惑/需要猜 | 30% 流失 |
| 🟡 **P2 摩擦** | 用户能继续但觉得麻烦/不优雅 | 5% 流失 |
| ⚪ **P3 建议** | 不影响使用但可以更贴心 | <1% |

## 四、易懂性量化检查表（可直接复制跑）

```markdown
## 易懂性快速检查表

### 1. 文案长度（≤ 15 字 = ✅）
- [ ] 主要按钮文案 ≤ 15 字
- [ ] 错误提示 ≤ 20 字
- [ ] 空状态标题 ≤ 15 字

### 2. 图标 + 文字匹配
- [ ] 纯图标按钮都有 aria-label
- [ ] 音乐版没有播放器图标（反之亦然）
- [ ] 收藏按钮用 ♡ / ❤️ 且 tooltip 写 "收藏 / 取消收藏"

### 3. 错误可见性
- [ ] 0 个错误只有 console.error（全部要有用户可见反馈）
- [ ] 至少有 toast / banner / inline error 三种展示方式之一
- [ ] 错误文案不说 HTTP 状态码 / 技术名词

### 4. 空状态处理
- [ ] 导入前空库：有引导文案 + 大号行动按钮
- [ ] 搜索无结果：有提示 + 建议
- [ ] 收藏夹空：有提示 + 引导

### 5. 加载 / 进度反馈
- [ ] 导入过程有进度条 / "N/M" 计数
- [ ] 播放加载有 spinner / 缓冲条
- [ ] 网络请求有超时 + 重试按钮

### 6. 可发现性
- [ ] 快捷键可查（有菜单入口）
- [ ] 新功能有首次 tooltip
- [ ] 设置项有说明文字
```

## 六、改进建议速查（历史踩过的坑）

> 这就是 UX Agent 自己的 Skill 反哺——**每发现一个新模式的坏味道就追加**。

### 模式 1：console.error 吞掉错误

| 位置 | 现状 | 建议 |
|---|---|---|
| src/*.js 所有 catch block | `console.error('xxx')` | 改为 toast/banner 通知用户 |
| 具体改法 | 加一个全局 `window.showToast(msg, type)` 函数 | type = 'info' / 'warn' / 'error' |

### 模式 2：空库状态无引导

| 位置 | 现状 | 建议 |
|---|---|---|
| index.html | 只有 `<input id="search">` | body 最前面加 `<div id="empty-state" hidden>` |
| main.js | 没有 `if (items.length === 0)` 分支 | 加：无数据 → 显示引导卡片 |

### 模式 3：导入完成无上下文

| 位置 | 现状 | 建议 |
|---|---|---|
| store.js / import 相关 | "✓ 完成" | "✓ 已导入 N 首 → 点击开始播放 →" |

### 模式 4：搜索 placeholder 太模糊

| 位置 | 现状 | 建议 |
|---|---|---|
| index.html search input | "搜索音乐 / 视频…" | "按 标题 / 艺术家 / 文件名 搜索" |
