# 绿角犀播放器 · 拆分为多独立窗口

## Context（为什么改）

当前音乐与视频共用**同一个 OS 窗口、同一个 WebView2、同一个前端 `player` 单例与单一底栏**，仅靠侧边栏在窗口内切视图。用户希望「两个模式分开、不要同个界面」，并明确选择：**主窗 + 弹窗**、**按模式精简侧栏**、**双击文件按类型分流**。

目标形态：
- **主窗口(Hub)**：保留全部导航（音乐/视频/歌单/收藏/最近/统计/云盘/设置），点「音乐/视频」时弹出独立窗口。
- **音乐窗口**：精简侧栏（音乐库+歌单+收藏），独立播放器，只处理音频。
- **视频窗口**：精简侧栏（视频库），独立播放器，只处理视频。
- 双击/关联文件按扩展名分流：音频→音乐窗、视频→视频窗（未开则创建、已开则聚焦）。
- 每窗独立播放（状态/队列/播放模式互不干扰）。

**核心技术可行性**：每个 WebView2 控件是独立 document / 独立 JS 运行时，前端 `player`/`bottombar` 单例天然按窗口隔离，**无需把单例重构为多实例工厂**。只要所有窗口**共享同一个 WebView2 user-data-folder 与同一个 `CoreWebView2Environment`**（否则各窗一套 IndexedDB，媒体库/设置/进度不一致）。

## 实施方案

### 1. C#：进程级共享 + 多窗口模型

**新增 `clients/windows/GreenRhino/WindowRole.cs`**
- `enum WindowRole { Hub, Music, Video }` + `IsAudioExt(ext)` / `IsVideoExt(ext)`（复用现有 `MediaExts` 集合语义）。

**新增 `clients/windows/GreenRhino/WindowHost.cs`（static 单例）**，集中所有进程级资源，从 MainWindow 迁入：
- `LocalServer Server`、`DlnaCaster Caster`、`NotifyIcon Tray`、`bool ForceClose`——从 MainWindow 实例字段迁入共享。
- `Task<CoreWebView2Environment> GetEnvAsync()`：懒加载**唯一一次** `CoreWebView2Environment.CreateAsync(rt, userData, opts)`（内含 `wv2data` 目录与现有 `--disable-gpu`/`--disable-accelerated-video-decode`/var 参数）。**所有窗口统一 `await webView.EnsureCoreWebView2Async(WindowHost.GetEnvAsync())`**——同进程对同一 user-data-folder 只能建一个 environment。
- `Dictionary<WindowRole, MainWindow> Windows` + `OpenOrFocus(role, files?)`（不存在则建、存在则聚焦并派发文件）。
- `RouteExternalFiles(paths)`：按 `IsAudioExt/IsVideoExt` 把双击/管道来的文件分流到 Music/Video 窗口（无媒体则聚焦 Hub）。
- 转码去重 `_transcoding`/`_transLock`、默认播放器单次注册 `_autoRegisterChecked` 提为进程级。

**改 `clients/windows/GreenRhino/App.xaml`**：移除 `StartupUri="MainWindow.xaml"`（不再由 WPF 自动建唯一窗）。

**改 `clients/windows/GreenRhino/App.xaml.cs`**：
- `OnStartup`：`base.OnStartup(e)` 后 `new MainWindow(WindowRole.Hub).Show()`；单实例管道回调从固定 `win.OpenExternalFiles` 改为 `WindowHost.RouteExternalFiles(paths)`。

**改 `clients/windows/GreenRhino/MainWindow.xaml.cs`**：
- 构造带 `WindowRole role`；`Title` 按角色命名；移除/上移托盘与 `_server.Start()`（整体迁到 WindowHost，服务只启动一次）。
- `OnSourceInitialized`：改用 `WindowHost.GetEnvAsync()` 建环境；在注入脚本中追加 `window.__winRole='hub'|'music'|'video'`；导航仍指 `http://127.0.0.1:port/`。
- `OnWebMessage` 新增 `openWindow` 分支（`{type:'openWindow', role}`）→ `WindowHost.OpenOrFocus(role)`（供前端主窗"打开音乐/视频弹窗"、弹窗"打开另一模式/回主窗"）。
- `OnClosing`：`if(!WindowHost.ForceClose){ e.Cancel=true; this.Hide(); return; }`（任一窗点 ✕ 只最小化到托盘）；`OnClosed` 只清理自身 `_videoBlobWriters`/`webView`，**不**停 `Server`/托盘（迁到 `App.OnExit`）。
- `OpenExternalFiles(list)` 复用现有 `EnqueuePaths`+`FlushPendingFiles`，向**本窗口自己的** `webView` 注入 `__hostOpen`。

**不改 `SingleInstance.cs`**：仍单进程（Mutex + 管道转发）；多窗口即进程内多 MainWindow，天然满足同进程共享 user-data-folder 的约束。

### 2. 前端：按窗口角色渲染

**改 `src/main.js`**：
- 顶部 `const ROLE = window.__winRole || 'hub'`。
- 页面构建按角色裁剪：
  - Hub：全量视图；`music/video` 导航点击改为 `window.chrome.webview.postMessage({type:'openWindow', role:'music'|'video'})`，不再 `showPage('music'/'video')`；默认落 `recent`。
  - Music：仅 `music` + `favorites({only:'music'})` + `playlists({only:'music'})`；默认落 `music`；侧栏隐藏 video/recent/stats/cloud。
  - Video：仅 `video`；默认落 `video`；侧栏隐藏 music/favorites/playlists/recent/stats/cloud。
- 主窗专有功能（目录导入、统计、设置、云盘、在线曲库等）不下沉到弹窗（侧栏已隐藏即不出现；弹窗保留单文件添加与拖拽导入）。
- 启动恢复（`getSettings().then` 中的 `lastMode`/`lastPlayedId` → `showPage`）：**仅 Hub 执行**，弹窗不跨类型恢复（双击文件由现有 `__hostOpened` 守卫接管）。

> 每窗独立 document，`initBottomBar`/`initGestures`/`buildQueue`/快捷键/MediaSession/`__hostOpen`/`player` 单例按窗口天然隔离，**无需改动**。

**改 `src/ui/favorites.js`、`src/ui/playlists.js`**：`refresh` 内 `list.filter(m => !only || m.type === only)`；`playlists.js` 的智能列表 `getAllMedia()` 处同过滤，`openDetail` 对非类型项灰显跳过。Video 窗口不建这两个页面。

### 3. 数据一致性

- 同 origin + 同 user-data-folder → IndexedDB / localStorage / Service Worker 由同一浏览器进程共享，各窗读写同一份**无需复制**。
- Service Worker：所有窗注册同一 `/sw.js`，合并为一个实例，网络优先策略保证各窗最新前端。
- 写并发本可接受：进度落盘各 `id` 独立、仅同一文件双窗同时播才碰撞（极低，v1 不加锁）；统计 `+1` 轻微少计非关键。仅 `lastPlayedId`/`lastMode` 跨窗覆盖，已用「仅 Hub 恢复」规避。

### 4. 构建

- 构建链 `build-windows.bat`（copy-web.mjs → wwwroot.zip → dotnet publish）**保持不变**。
- **必须递增** `src/sw.js` 的 `CACHE = 'greenrhino-v11' → 'greenrhino-v12'`（前端本轮有改动，避免缓存锁死旧界面）。
- 前端同步 `clients/windows/GreenRhino/wwwroot/` 并重打 `wwwroot.zip`；C# 改后重新 `dotnet publish --self-contained`，覆盖桌面副本重启。

## 验证

1. 重启应用：Hub 窗口正常、托盘生效。
2. Hub 侧栏点「音乐」→ 弹出音乐窗；点「视频」→ 弹出视频窗；互相跳转与「回主窗」正常；重复点不重复建只聚焦。
3. 双击 mp3 → 音乐窗播放；mp4 → 视频窗播放；窗已开只聚焦。
4. 音乐窗放歌、视频窗放片，两侧进度/队列/播放模式互不影响；暂停一侧不影响另一侧。
5. 在 Hub 导入/改设置，音乐/视频窗即时可见（验证共享 user-data-folder；`%LOCALAPPDATA%\GreenRhino\wv2data` 只一套）。
6. 各窗点 ✕ 只缩托盘；托盘「退出」才全部关闭、进程退出、日志无异常。
7. 视频窗放 HEVC：ffmpeg 转码 + 进度条 + 原生兜底仍正常（转码去重为进程级）。
