# 绿角犀播放器 · 出包总览（本机速查）

> 沙箱无法编译原生包，以下均在你本机执行。每个平台一个脚本/文档，双击或按步骤跑即可。
> 详细工程步骤见 `README.md`；项目总路由见 `R0.md`。

## 共通前置（一次性）
```bash
cd clients
npm i                 # 装 playwright（SVG 光栅化）
node build-assets.mjs # 生成四平台图标 + assetlinks.json
node copy-web.mjs     # 复制 web 到 windows/wwwroot 与 ios/wwwroot
```

## 平台速查表

| 平台 | 本机命令 | 前置 | 产出 | 关键依赖 |
|------|----------|------|------|----------|
| Windows | 双击 `build-windows.bat` | .NET 8 SDK | `windows/GreenRhino/publish/GreenRhino.exe`（自包含） | 无 |
| Android | 双击 `build-android.bat` | JDK 17 + Android SDK | `android/app/build/outputs/bundle/release/app-release.aab` | 先部署 PWA 到 https；assetlinks SHA256 填真指纹 |
| 华为 | 双击 `build-huawei.bat`（引导） | 已部署 https 站点 | AppGallery 上架 | 控制台提交 + listing 资料 |
| iOS | 按 `build-ios.md` 在 Mac 执行 | macOS + Xcode 15+ + XcodeGen | `build/ipa/GreenRhino.ipa` | 需 Mac，Windows 编不了 |

## 共性注意
- TWA（Android）与华为都依赖**先部署 PWA 到公网 https**，并在站点根放置 `/.well-known/assetlinks.json`；SHA256 指纹在部署/签名后替换（`build-android.bat` 已自动改 `strings.xml` 域名，但指纹需手动填）。
- iOS 内嵌 `wwwroot` 离线优先，**不依赖远程站点**，但首次安装需联网下载 App。
- 出包结果回传项目助手，验收入 `R0.md` 行程并关单。

## CI 自动出包（可选 · 绕开本机工具链）

推到 GitHub 后，打 tag `v*` 或手动 `workflow_dispatch` 即云端构建，本机无需装 .NET/Android Studio/Xcode（iOS 用 GitHub macos runner，没 Mac 也能出 IPA）。

启用步骤：
1. 仓库已 `git init`（本地 `main` 分支，首提交 `c3ae11b`，105 文件，未推送；`.workbuddy/` 与密钥已 `.gitignore` 排除）。你只需补远程并推送：
   `git remote add origin <你的仓库> && git push -u origin main`
2. 仓库 **Settings → Secrets → Actions** 配置以下 secrets（仅用到的平台填）：
   | Secret | 用途 | 备注 |
   |--------|------|------|
   | `ANDROID_PWA_URL` | TWA 启动的 https 站点 | 默认 greenrhino.example.com |
   | `ANDROID_KEYSTORE_BASE64` | 签名 keystore 的 base64 | 本机 `certutil -encode upload-keystore.jks ks.b64`（Windows）或 `base64 -w0 upload-keystore.jks` |
   | `ANDROID_KEYSTORE_PASSWORD` | keystore 密码 | 与本机脚本一致（默认 android） |
   | `ANDROID_KEY_ALIAS` | 别名 | 默认 upload |
   | `ANDROID_KEY_PASSWORD` | 密钥密码 | 默认 android |
   | `IOS_TEAM_ID` | 10 位开发者 Team ID | 写入 project.yml |
   | `IOS_CERT_P12_BASE64` | 分发证书 p12 base64 | 上架必需 |
   | `IOS_CERT_PASSWORD` | p12 密码 | |
   | `IOS_PROVISIONING_BASE64` | mobileprovision base64 | App Store 描述文件 |
3. 打 tag：`git tag v1.0.0 && git push origin v1.0.0` → Actions 自动出四端包，去 Artifacts 下载。

> CI 工作流文件：`.github/workflows/build-{windows,android,ios,huawei}.yml`。本机 `.bat`/`.md` 仍可用，二者签名约定一致（local.properties 的 storeFile/storePassword/keyAlias/keyPassword）。
